Política de Privacidade

Fronteira Escura · atualizada em 17 de outubro de 2026

Este site

Este site só apresenta o canal. Ele não usa cookies, não tem formulários e não coleta dados de quem o visita.

Aplicativo "rclone-vps-canal"

O aplicativo "rclone-vps-canal" é uma ferramenta interna do canal. Somente a equipe do Fronteira Escura o usa, com a própria conta Google do canal, para ler e gravar os arquivos de produção dos vídeos (imagens, áudios e prévias) numa pasta do Google Drive, a partir de um servidor privado.

  • Ele acessa só os arquivos do Google Drive da conta que o autoriza, e não acessa dados de outras pessoas.
  • Os arquivos são usados apenas para produzir os vídeos do canal. Nada é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de IA.
  • A autorização de acesso fica guardada no servidor privado do canal, com acesso restrito, e nunca é publicada.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Aplicativo "Fronteira Escura Monitor" (Instagram)

O aplicativo "Fronteira Escura Monitor" é uma ferramenta interna do canal. Ele usa a API do Instagram, com a autorização da própria conta @fronteiraescura, para acompanhar o desempenho dos Reels do canal, a partir de um servidor privado.

  • Ele lê só dados da conta @fronteiraescura: a lista de Reels, os números de cada um (visualizações, alcance, curtidas, compartilhamentos, salvamentos e tempo médio assistido) e os comentários feitos nesses Reels (nome de usuário de quem comentou, texto e data).
  • Ele só lê. Não publica, não responde, não curte, não esconde nem apaga comentários e não lê mensagens diretas.
  • Os dados viram relatórios internos para a equipe do canal, guardados no servidor privado com acesso restrito. Nada é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de IA.
  • A autorização de acesso fica guardada no servidor privado do canal, com acesso restrito, e nunca é publicada. Ela pode ser revogada a qualquer momento no Instagram, em Configurações > Apps e sites.

Exclusão de dados

Se você comentou num Reel do canal e quer que o seu nome de usuário e o seu comentário sejam apagados dos relatórios internos, escreva para fronteiraescura@gmail.com com o assunto "Exclusão de dados" e o seu nome de usuário no Instagram. Os dados são apagados em até 30 dias e você recebe a confirmação por e-mail. Apagar o comentário no próprio Instagram também faz com que ele não seja mais lido nas próximas leituras.
